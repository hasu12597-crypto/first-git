# DORA 메트릭 수집 자동화

OSS 기반 SW 프로그래밍 과제입니다. GitHub Actions와 GitHub API로 DORA 4개 지표를 수집하고 대시보드와 결과 파일을 자동 생성합니다.

## AI 활용 공개

- 사용 도구: ChatGPT/Codex
- 사용 시기: 프로젝트 주제 선정, 문서 작성 및 코드 구성 단계
- 활용 범위: 프로젝트 아이디어 정리, README와 제안서 초안 작성, GitHub Actions 및 이슈 템플릿 구성 지원
- 입력 프롬프트 요약: GitHub Projects, DORA Metrics, GitHub Actions를 활용하는 프로젝트의 기능과 문서 구성을 제안하도록 요청함
- 검증 방법: 생성된 내용과 코드를 직접 검토하고, GitHub Actions 실행 결과와 실제 저장소 동작으로 확인함

AI가 제안한 내용을 프로젝트에 맞게 수정했으며, 제출 전 사실과 실행 결과를 직접 확인했습니다.

## 협업 개발 실습

이 저장소는 GitHub Projects, Issues, Pull Request, GitHub Actions를 활용한 협업 개발 실습 프로젝트입니다.
